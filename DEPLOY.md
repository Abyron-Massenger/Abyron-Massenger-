# Deploy

## Web
1. Create a GitHub repository.
2. Upload everything inside `web/` to the repository root.
3. Put your Supabase URL + anon key into `config.js`.
4. Enable GitHub Pages.
5. Open the HTTPS site.

## Supabase
1. Create a free Supabase project.
2. Run `supabase/schema.sql` in SQL Editor.
3. Enable Realtime for `messages`.
4. Replace development RLS policies before public launch.

## Android
The browser cannot replace the native nearby layer. Build an Android companion around
`android-transport/README.md`, then share the same application-level ciphertext format.
